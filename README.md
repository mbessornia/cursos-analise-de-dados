## 🎯 Sobre o Repositório

Este espaço serve como um registro da minha jornada de aprendizado. O objetivo é aplicar os conceitos teóricos em projetos práticos, documentar meu progresso e criar um portfólio consolidado dos conhecimentos adquiridos. 

---

## 📚 Estrutura da Trilha

O repositório está organizado em pastas, cada uma correspondendo a um nível da trilha. Dentro de cada nível, estão os cursos contidos em cada nível. Inicialmente estou utilizando como guia a trilha de "Carreiras" oferecida pela plataforma Alura. A intenção é seguir a ordem cronológica do aprendizado.

* **🔓 `Base - Python, Estatística, SQL e Excel`**

* **🔒 `Nível 1 - SQL, Power BI, Pandas e Storytelling`**

* **🔒 `Nível 2 - Big Query, APIs, Automação e Estatística Avançada`**

* **🔒 `Nível 3 - NoSQL, ETL na Nuvem, Machine Learning e Visualizações Avançadas`**
